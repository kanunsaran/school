# สิ่งที่ครูแนะแนวต้องตรวจสอบ — ระบบแนะแนวจากผล RIASEC

ไฟล์ที่ใช้ตรวจ: **ครูตรวจสอบ-ระบบแนะแนว-RIASEC.xlsx** (ในโฟลเดอร์เดียวกัน)

**ส่งให้ครูแนะแนว: ครูตรวจสอบ-ฉบับย่อ-RIASEC.xlsx** (238 แถว) — มีเฉพาะข้อคำถาม 60 ข้อ (IOC), สาขาขัดกับ O*NET, เกณฑ์ระบบ, ข้อความที่นักเรียนเห็น (ไม่รวมคำอธิบายทักษะ 216 ข้อ) และคำแนะนำรายสาขา 90 สาขา ส่วนที่เหลือของฉบับเต็มเป็นเรื่องเทคนิคหรือข้อมูลที่โรงเรียนให้มาเอง ผู้พัฒนาตรวจเองได้
ไฟล์นี้สร้างจากข้อมูลและข้อความที่หน้าเว็บใช้อยู่จริง ถ้าแก้ระบบแล้ว สร้างใหม่ได้ด้วย `node scripts/teacher-review-xlsx.mjs`

ทุกชีตมีคอลัมน์ให้กรอกทางขวา: **ครูตรวจ (✓/✗)**, **ข้อเสนอแก้ไข**, **ผู้ตรวจ/วันที่** — กรอกแล้วส่งไฟล์คืนผู้พัฒนา

## ต้องตรวจก่อนใช้กับนักเรียน (สำคัญที่สุด)

| ชีต | ตรวจอะไร | ทำไม |
|---|---|---|
| 11-ข้อคำถาม60ข้อ | ข้อคำถามที่นักเรียนตอบจริง 60 ข้อ (ด้านละ 10) — ผู้เชี่ยวชาญ 3 คนให้คะแนน +1 ตรง / 0 ไม่แน่ใจ / −1 ไม่ตรง กับด้านที่ระบุ ไฟล์คำนวณ IOC ให้ (≥ 0.5 ใช้ได้) | ถ้าข้อคำถามวัดผิดด้าน ผลทุกอย่างหลังจากนั้นผิดตาม — และเป็นหลักฐานความตรงเชิงเนื้อหาสำหรับรายงาน |
| 2-สาขาขัดกับONET | 27 สาขาที่ “ด้านหลัก” ในไฟล์โรงเรียนต่างจากรหัสความสนใจของอาชีพตัวแทนใน O*NET — เลือกว่าจะใช้ด้านใด | ด้านหลักของสาขาใช้ตัดสินระดับความสอดคล้องและสาขาที่แนะนำ ตอนนี้ระบบยังใช้ของโรงเรียน |
| 1-เกณฑ์ระบบ | เกณฑ์ 14 ข้อ เช่น ระดับสูง/ปานกลาง/ต่ำ, “ใกล้เคียง” = ห่างไม่เกิน 2 คะแนน, การนับอันดับร่วม (ร่วม 3 สองด้าน → ถัดไปอันดับ 5) | ผู้พัฒนาตั้งขึ้นเอง ยังไม่มีแหล่งอ้างอิงรับรอง |
| 4-ข้อความที่ระบบเขียน | กิจกรรมทั่วไป 6 ด้าน, คำถามทบทวนตัวเอง, ประโยคแม่แบบ, เหตุผลของระดับ, คำอธิบายทักษะที่ควรพัฒนา 216 ข้อ | เขียนโดยระบบ (AI) ยังไม่ผ่านครู — หน้าเว็บติดป้าย “คำแนะนำทั่วไปของระบบ” ไว้ |

## ควรตรวจในช่วงทดลองใช้

| ชีต | ตรวจอะไร |
|---|---|
| 3-ข้อมูลสาขา | เนื้อหาจาก Excel ของโรงเรียน 90 สาขา (คุณลักษณะ ทักษะ คำแนะนำ วิชา อาชีพ มหาวิทยาลัย หลักสูตร) — ยังไม่ได้ตรวจกับแหล่งภายนอก |
| 5-คำจับคู่ด้าน / 6-คำลักษณะงาน | คำที่ระบบใช้ตัดสินว่าวลีของสาขาเชื่อมกับความสนใจด้านใด และงานของสองสาขาคล้ายกันหรือไม่ |
| 7-ผลการจับคู่วลี | ผลจริงทุกวลี (564 แถว) ว่าระบบจัดให้ด้านใด — 77 วลีไม่ถูกจับคู่ (ไม่ถูกใช้ในคำอธิบาย) |
| 8-กิจกรรมจากข้อมูลโรงเรียน | การแยกคำแนะนำเป็นข้อ การตัดข้อเตรียมสอบ และข้อที่ใช้เป็น “กิจกรรม” |

## เรื่องที่ระบบไม่ได้อ้าง / ข้อจำกัด

- ผล RIASEC บอก **ความสนใจ** — ไม่ได้วัดความสามารถ ผลการเรียน คุณสมบัติรับเข้า หรือโอกาสสอบติด
- แบบประเมิน 60 ข้อยังไม่มีข้อมูลความเชื่อมั่น/ความตรงกับนักเรียนจริง — แนะนำเก็บข้อมูลช่วงทดลองใช้ (เช่น Cronbach's alpha รายด้าน)
- ทดสอบระบบด้วยคะแนนสมมติเท่านั้น ยังไม่มีนักเรียนจริงทดลองใช้
- ข้อมูล O*NET เป็นอาชีพในสหรัฐฯ ใช้เป็นข้อมูลประกอบ ไม่ได้ใช้ตัดสินผล
- เกณฑ์รับเข้า (myTCAS) ดึงตอนเปิดดู — ข้อมูล TCAS ปีการศึกษา 2570 ยังประกาศไม่ครบทุกรอบ
