# แบบสอบถามความพึงพอใจของนักเรียน (Guidance KKW)

## ในโฟลเดอร์นี้มีอะไร
- `screens-v2/` — ภาพหน้าจอฝั่งนักเรียน 17 ภาพ (กดเปิดส่วนที่ถามไว้แล้ว) (ใส่ในฟอร์ม)
- `create-form.gs` — สคริปต์ Google Apps Script สร้าง Google Form พร้อมภาพและคำถามทั้งหมด

## วิธีสร้างฟอร์ม (ประมาณ 5 นาที)
1. อัปโหลดโฟลเดอร์ `screens-v2` ขึ้น Google Drive (ลากทั้งโฟลเดอร์ไปวางใน My Drive)
2. เปิด https://script.google.com → **New project** → ลบโค้ดเดิม → วางโค้ดจาก `create-form.gs` → กด Save
3. เลือกฟังก์ชัน `createSurvey` แล้วกด **Run** → อนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to project → Allow)
4. ดูลิงก์ใน **Execution log**: ลิงก์แก้ไขฟอร์ม, ลิงก์ส่งให้นักเรียน และไฟล์ Google Sheets ที่เก็บคำตอบ

## โครงสร้างแบบสอบถาม
| ตอน | เนื้อหา |
|---|---|
| 1 ข้อมูลทั่วไป | เพศ ระดับชั้น แผนการเรียน อุปกรณ์ที่ใช้ เคยใช้เว็บด้านการศึกษาต่อหรือไม่ |
| 2 ทดสอบการใช้งาน (8 ส่วน) | แต่ละส่วนมีภาพหน้าจอ + ภารกิจให้ลองทำ + ผลการทำภารกิจ (ทำได้เอง / ต้องมีคนช่วย / ทำไม่ได้) + ความพึงพอใจ 5 ระดับ + ปัญหาที่พบ |
| 3 ความพึงพอใจภาพรวม | 5 ด้าน: การออกแบบ, ความง่ายในการใช้งาน, เนื้อหาและความถูกต้อง, ประสิทธิภาพ, ประโยชน์ที่ได้รับ |
| 4 ข้อเสนอแนะ | จะแนะนำให้เพื่อนไหม (1–5), สิ่งที่ชอบ, สิ่งที่ควรปรับปรุง, ฟีเจอร์ที่อยากได้ |
