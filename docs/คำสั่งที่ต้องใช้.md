# คำสั่งที่ต้องใช้ (พิมพ์ใน Terminal)

> **อ่านก่อน:** บรรทัดที่ขึ้นต้นด้วย `kanun@MacBook-Air-khxng-kanun ??? %` คือ **ต้องอยู่โฟลเดอร์ไหน** — ส่วนที่ต้องพิมพ์คือข้อความ **หลัง `%`**
>
> | เห็นใน Terminal | อยู่ที่โฟลเดอร์ | ใช้ทำอะไร |
> |---|---|---|
> | `kanun@MacBook-Air-khxng-kanun project %` | `~/Desktop/project` (โฟลเดอร์หลัก) | **คำสั่งเกือบทั้งหมด** — เปิดระบบ, commit, deploy |
> | `kanun@MacBook-Air-khxng-kanun Rm %` | `~/Desktop/project/Rm` (หน้าเว็บ) | เช็กโค้ดหน้าเว็บ (build / lint) เท่านั้น |
> | `kanun@MacBook-Air-khxng-kanun projectrmb %` | `~/Desktop/project/projectrmb` (backend) | รัน backend แบบดูข้อความสด |
>
> ⚠️ **ห้ามพิมพ์คำสั่ง `git` ตอนเป็น `Rm %`** — ในโฟลเดอร์ `Rm` มี git ชุดเก่าซ้อนอยู่ จะ commit ผิดที่และเว็บไม่ deploy ให้กลับไป `project %` ก่อนเสมอ

---

## 0. ย้ายไปโฟลเดอร์ที่ถูก

เปิด Terminal ใหม่จะอยู่ที่ `kanun@MacBook-Air-khxng-kanun ~ %` ให้พิมพ์:

```
kanun@MacBook-Air-khxng-kanun ~ % cd ~/Desktop/project
kanun@MacBook-Air-khxng-kanun project %
```

| อยากไป | พิมพ์ |
|---|---|
| โฟลเดอร์หลัก `project %` (จากที่ไหนก็ได้) | `cd ~/Desktop/project` |
| `Rm %` | `cd ~/Desktop/project/Rm` |
| `projectrmb %` | `cd ~/Desktop/project/projectrmb` |
| ถอยกลับขึ้นไป 1 ชั้น (เช่น `Rm %` → `project %`) | `cd ..` |
| ดูว่าตอนนี้อยู่ไหน | `pwd` |

## 1. เปิดระบบบนเครื่อง (localhost)

```
kanun@MacBook-Air-khxng-kanun project % ./scripts/dev.sh
```
ทำให้ 3 อย่าง: เช็ก/เปิด MySQL (XAMPP) → เปิด backend พอร์ต 3000 → เปิดหน้าเว็บพอร์ต 5173 แล้วทดสอบดึงข่าวให้
เสร็จแล้วเปิด **http://localhost:5173/login**

| อยาก | พิมพ์ (ที่ `project %`) |
|---|---|
| ดูว่าอะไรเปิด/ปิดอยู่ | `./scripts/dev.sh status` |
| ปิดระบบ | `./scripts/dev.sh stop` |
| ปิดแล้วเปิดใหม่ (แก้อาการแปลก ๆ) | `./scripts/dev.sh stop` แล้ว `./scripts/dev.sh` |
| ดู error ของ backend | `tail -30 /tmp/rm-backend.log` |
| ดู error ของหน้าเว็บ | `tail -30 /tmp/rm-vite.log` |

> ปิดหน้าต่าง Terminal ได้ ระบบยังรันต่อ (ปิดจริงด้วย `./scripts/dev.sh stop` หรือปิดเครื่อง)

## 2. เวลามีปัญหา

### "โหลดข่าวสารไม่สำเร็จ" / "เชื่อมต่อเซิร์ฟเวอร์ไม่ได้" / หน้าว่าง ข้อมูลไม่ขึ้น
แปลว่า **backend (พอร์ต 3000) ไม่ได้เปิด**
```
kanun@MacBook-Air-khxng-kanun project % ./scripts/dev.sh status
kanun@MacBook-Air-khxng-kanun project % ./scripts/dev.sh
```
แล้วกดปุ่ม **"ลองใหม่"** บนหน้าเว็บ หรือกด `Cmd + R` รีเฟรช

### เปิด http://localhost:5173 ไม่ได้เลย (This site can't be reached)
หน้าเว็บ (พอร์ต 5173) ไม่ได้เปิด → พิมพ์ `./scripts/dev.sh` เหมือนข้างบน

### ขึ้น "ฐานข้อมูล … ปิดอยู่" / backend เปิดไม่ขึ้น
- เปิดแอป **XAMPP** (Applications → XAMPP → manager-osx) → แท็บ Manage Servers → กด **Start** ที่ **MySQL Database**
- แล้วพิมพ์ `./scripts/dev.sh` อีกครั้ง
- ยังไม่ได้ ดูสาเหตุ: `tail -30 /tmp/rm-backend.log`

### "Port 3000 / 5173 is already in use" (พอร์ตถูกใช้อยู่)
```
kanun@MacBook-Air-khxng-kanun project % ./scripts/dev.sh stop
kanun@MacBook-Air-khxng-kanun project % ./scripts/dev.sh
```

### ล็อกอินแล้วเด้งออก / "กรุณาเข้าสู่ระบบใหม่"
token หมดอายุ (1 วัน) → ล็อกอินใหม่ได้เลย

### หน้าเว็บยังเป็นแบบเก่าหลังแก้โค้ด / หลัง deploy
กด `Cmd + Shift + R` (รีเฟรชแบบล้างของเก่า)

## 3. เช็กโค้ดก่อน commit (ไม่บังคับ แต่ควรทำ)

```
kanun@MacBook-Air-khxng-kanun project % cd Rm
kanun@MacBook-Air-khxng-kanun Rm % npm run build
kanun@MacBook-Air-khxng-kanun Rm % npm run lint
kanun@MacBook-Air-khxng-kanun Rm % cd ..
kanun@MacBook-Air-khxng-kanun project %
```
- `npm run build` ต้องจบด้วย `✓ built in …` (ถ้าแดง = โค้ดหน้าเว็บพัง ห้าม deploy)
- `npm run lint` มี warning ได้ แต่ไม่ควรมี `error`
- **อย่าลืม `cd ..` กลับมา `project %` ก่อนใช้ git**

## 4. Commit และขึ้นเว็บจริง (deploy)

**ระบบ deploy อัตโนมัติ:** แค่ `git push` ขึ้น branch `main` → GitHub Actions จะ build และอัปโหลดขึ้นเซิร์ฟเวอร์เอง (ประมาณ 5–10 นาที)

ทุกคำสั่งในหัวข้อนี้พิมพ์ที่ **`project %`**

```
kanun@MacBook-Air-khxng-kanun project % git status
kanun@MacBook-Air-khxng-kanun project % git add -A Rm/src projectrmb docs scripts db
kanun@MacBook-Air-khxng-kanun project % git commit -m "อธิบายสั้น ๆ ว่าแก้อะไร"
kanun@MacBook-Air-khxng-kanun project % git push
```

| คำสั่ง | ทำอะไร |
|---|---|
| `git status` | ดูว่าไฟล์ไหนถูกแก้ (แดง = ยังไม่ได้ add, เขียว = add แล้ว) |
| `git add -A Rm/src projectrmb docs scripts db` | เลือกไฟล์โค้ด/เอกสารที่จะส่ง (ไม่เอาไฟล์ Excel/ไฟล์ชั่วคราวที่หน้าโปรเจกต์) |
| `git add ชื่อไฟล์` | เลือกเฉพาะไฟล์นั้น |
| `git commit -m "ข้อความ"` | บันทึกการแก้ไข 1 ครั้ง พร้อมคำอธิบาย |
| `git push` | ส่งขึ้น GitHub → **deploy ขึ้นเว็บอัตโนมัติ** |
| `git log --oneline -5` | ดู commit ล่าสุด 5 อัน |
| `git diff` | ดูว่าแก้อะไรไปบ้าง (กด `q` เพื่อออก) |

### ดูว่า deploy เสร็จหรือยัง
- เปิด **https://github.com/kanunsaran/school/actions**
  - 🟡 วงกลมหมุน = กำลัง deploy • ✅ เขียว = ขึ้นเว็บแล้ว • ❌ แดง = ไม่สำเร็จ (กดเข้าไปดูว่าพังขั้นไหน)
- เว็บจริง: **http://178.128.58.65:5173** (เปิดแล้วกด `Cmd + Shift + R`)

### push ไม่ผ่าน
| ข้อความ | แก้ |
|---|---|
| `rejected … fetch first` / `non-fast-forward` | `git pull --rebase` แล้ว `git push` อีกครั้ง |
| `nothing to commit` | ไม่มีอะไรแก้ หรือยังไม่ได้ `git add` |
| `not a git repository` หรือ commit แล้วเว็บไม่เปลี่ยน | อาจอยู่ `Rm %` → `cd ~/Desktop/project` แล้วทำใหม่ |

## 5. เซิร์ฟเวอร์จริง (ใช้เมื่อเว็บจริงมีปัญหาเท่านั้น)

```
kanun@MacBook-Air-khxng-kanun project % ssh root@178.128.58.65
root@... :~# cd ~/school
```

| อยาก | พิมพ์ (บนเซิร์ฟเวอร์ ที่ `~/school`) |
|---|---|
| ดูว่าแต่ละส่วนรันอยู่ไหม | `docker compose ps` |
| ดู error ของ backend | `docker compose logs backend --tail 50` |
| รีสตาร์ต backend / หน้าเว็บ | `docker compose restart backend frontend` |
| ดูว่าเซิร์ฟเวอร์เป็นโค้ดเวอร์ชันไหน | `git log --oneline -1` |
| ออกจากเซิร์ฟเวอร์ | `exit` |
